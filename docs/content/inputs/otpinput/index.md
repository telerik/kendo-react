# KendoReact OTPInput Overview

## Key Features

-   [Controlled Mode]({% slug controlled_otpinput %})&mdash;Use the `value` and `onChange` props to take full control of the OTPInput value from your component state.
-   [Types]({% slug types_otpinput %})&mdash;The OTPInput supports `text`, `password`, and `number` input types to cover common OTP entry scenarios.
-   [Separator]({% slug separator_otpinput %})&mdash;Group cells visually with string or icon separators to improve readability of longer codes.
-   [Forms Support]({% slug forms_support_otpinput %})&mdash;Integrate the OTPInput with the KendoReact Form component for built-in validation and error messaging.
-   [Placeholder]({% slug placeholder_otpinput %})&mdash;Provide a single-character placeholder to guide users on the expected input format.
-   [Appearance]({% slug appearance_otpinput %})&mdash;Configure the size, fill mode, roundness, and spacing of the OTPInput cells.
-   [Disabled State]({% slug disabled_otpinput %})&mdash;Prevent user interaction by disabling the component.
-   [Read-Only State]({% slug readonly_otpinput %})&mdash;Display a value that users can read but not modify.
-   [Adaptive Rendering]({% slug adaptive_rendering_otpinput %})&mdash;Use the `inputAttributes` property to configure the on-screen keyboard type displayed on touch devices.
-   [Events]({% slug events_otpinput %})&mdash;React to value changes, cell focus, and blur events.
-   [Keyboard Navigation]({% slug keyboard_navigation_otpinput %})&mdash;The OTPInput ships with full keyboard support including paste handling.
-   [Custom Attributes]({% slug custom_attributes_otpinput %})&mdash;Apply custom HTML attributes to every input cell, such as `autocomplete="one-time-code"`.

> To learn more about the appearance, anatomy, and accessibility of the OTPInput, visit the [Progress Design System documentation](https://www.telerik.com/design-system/docs/components/otpinput/)—an information portal offering rich component usage guidelines, descriptions of the available style variables, and globalization support details.
