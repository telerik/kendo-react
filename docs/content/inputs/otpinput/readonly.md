# Read-Only OTPInput

Setting the [`readOnly`]({% slug api_inputs_otpinputprops %}#readonly) prop to `true` renders an OTPInput that displays its value but cannot be edited. Unlike the disabled state, a read-only OTPInput can still receive focus.
