# Types

The OTP Input component provides support for various input types. The component is suitable for inserting numeric values, passwords, or text.

You can set the [`type`]({% slug api_inputs_otpinputprops %}#type) property of the component to:

-   `number`&mdash;Accepts only numeric values.
-   `password`&mdash;The component can be used as a password input.
-   `text` (default)&mdash;Allows to insert letters and numbers.
